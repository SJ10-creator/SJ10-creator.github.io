Privacy Policy

Last updated: October 20, 2026

Purpose

rclone-research is a personal-use application that connects to Google Drive using rclone.

Data Access

The application accesses Google Drive files only with the account owner's authorization.

Data Use and Storage

Drive data is used for personal research file management and synchronization. OAuth credentials are stored locally in the user's rclone configuration. This website does not receive Drive files or tokens.

Data Sharing

The application does not sell Google user data or share it with advertisers.

Access Revocation

The user can revoke Google Drive access at https://myaccount.google.com/connections.
